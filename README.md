Simple Dictionary

About the Project

Simple Dictionary is a beginner-friendly Java console application that allows users to manage and search for word meanings.

Features

- Search for a word and view its meaning
- Add new words
- Update existing meanings
- Delete words
- Display all available words
- Exit the application

Technologies Used

- Java
- HashMap
- Scanner
- Eclipse IDE

How to Run

1. Download or clone this repository.
2. Open the project in Eclipse or any Java IDE.
3. Run the Java file.
4. Select an option from the menu.
5. Enter the required word or meaning.

Concepts Used

- Java Basics
- Variables and Data Types
- Conditional Statements
- Loops
- HashMap
- Scanner
- CRUD Operations
